# Recordings in this book

Human recordings used as "hear a person" references. All come from Wikimedia Commons and were found on 25 Nov 2026.
Each one here has been trimmed, mixed to mono, loudness-levelled (−18 LUFS) and converted to 64 kbps MP3. Those
are modifications; the CC BY-SA ones are shared under the same licence as their originals. The book shows these
credits wherever the clip plays.

No openly licensed recordings were found for the core warm-ups (humming, sirens, straw, scales, arpeggios). For those the
book offers **Your reference** (record yourself once you can do it) and a **Watch a teacher** search link.
`docs/recording-guide.md` lists what to record so the missing ones can be added for everyone.
